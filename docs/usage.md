# SitePulse usage — M1

Install in a Python 3.12+ virtual environment using `python -m pip install -e ".[dev]"`.

Available commands:

- `sitepulse --help`: list currently implemented CLI commands.
- `sitepulse version`: print installed version.
- `sitepulse doctor`: show runtime diagnostics and fail if Python is older than 3.12.

The intended `add`, `remove`, `list`, `check`, `monitor`, `history`, `report`, and `config` commands **are not yet available**; they are scheduled for M3–M8.
